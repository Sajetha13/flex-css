# 🌃 Flex CSS Demo

A simple webpage built to explore **CSS Flexbox** layout techniques.

## What’s the purpose?

To visually understand how Flexbox works for:

- Centering elements
- Aligning content both vertically and horizontally
- Creating responsive sections (or just pretty alignments)

## What I used

- HTML5  
- CSS3 (`display: flex`, `justify-content`, `align-items`)

## Live Preview

Check it out 👉 [Flex Demo](https://sajetha13.github.io/flex-css/)

## Notes

This is a basic layout and meant for **learning** and **showcasing** Flexbox properties.  
Responsive behavior is minimal (for now 👀).
